# CARTES TECHNIQUES

1. **Type d’agent**.
2. **Caractéristiques de l’agent** :
    - **LPA (Limite de Points d’Action)** : Le coût total des actions que l’agent peut effectuer pendant son activation. Certaines règles changent les LPA d’un agent. Le total ne peut jamais dépasser -1 ou +1 par rapport à sa LPA normale (cela l’emporte sur toutes les autres règles). Cette valeur est aussi utilisée pour déterminer le contrôle des marqueurs.
    - **Mouvement (Mvt)** : La distance de déplacement d’un agent. Ne peut jamais être inférieure à 4” (cela l’emporte sur toutes les autres règles de changement de caractéristiques).
    - **Sauvegarde (Svg)** : Lé résultat requis pour réussir un jet de défense lors d’un tir contre l’agent.
    - **Points de Vie (PV)** : Le nombre de points de vie de départ de l’agent.
*Si les caractéristiques d’un agent ou de ses armes changent pendant une action, appliquez le changement seulement une fois l’action terminée. Notez que les changements aux règles des armes s’appliquent immédiatement.*
3. **Caractéristiques de l’arme** :
    - Les pages de sélection d’une kill team indiquent les armes d’un agent. Si elles ne précisent rien, un agent possède toutes les armes de sa carte technique.
    - **Type d’arme** : Arme de tir ou arme de mêlée (Combat ou riposte).
    - **Attaques (A)** : Le nombre de dés d’attaque à jeter quand un agent utilise cette arme.
    - **Dégâts (D)** : Les dégâts que chaque dé inflige avec cette arme. La première valeur indique les ***Dégâts Normaux*** tandis que la seconde indique les ***Dégâts critiques***. Des armes auront parfois le même nom principal mais des noms secondaires différents, représentés entre parenthèses. Si une règle réfère au nom principal, elle inclut toutes les armes et profils ayant ce nom principal.
4. **Règles de l’arme** :
    - Les règles additionnelles qui s’appliquent quand l’agent utilise cette arme.
5. **Règles additionnelles** :
    - Les règles additionnelles qui s’appliquent à l’agent.
   - Les actions uniques que l’agent peut faire.
6. **Mots-clés** :
   - Utilisés pour identifier l’agent pour les besoins de certaines règles. Ils sont indiqués par une police de caractère de type **MOT-CLÉ GRAS**. Les mots clés en orange avec un symbole de crâne sont des mot-clés de faction qui servent à identifier tous les agents de la kill team en question.
7. **Taille du socle** :
    - Le diamètre du socle mesuré en millimètres.
