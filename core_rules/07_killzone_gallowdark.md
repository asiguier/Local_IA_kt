# KILLZONE : GALLOWDARK

## MUR DU GALLOWDARK

Un mur du Gallowdark est un terrain Lourd de type Mur. Certains murs incluent une écoutille.
- Un agent ne peut pas se déplacer sur ou à travers un Mur (cela l’emporte sur toutes les autres règles).
- On ne peut pas voir par-dessus ni à travers un Mur.
- Une distance ne peut pas être mesurée par-dessus ou à travers un Mur, elle doit toujours être mesurée en le contournant, par le plus court chemin possible, sauf s’il faut mesurer jusqu’à des zones spécifiques de la killzone (centre de la killzone, zone d’insertion, etc.).
- Pour les règles de couvert et masqué, seul le coin ou l’extrémité d’un Mur peut être interposé, sauf si l’agent actif l’a dépassé.

L’agent B n’est pas à couvert car il n’y a pas de coin ou d’extrémité de mur interposé. Les petites excroissances du mur ne comptent pas pour un coin ou une extrémité, il faut que ce soit la structure principale du mur qui soit le coin ou l’extrémité.
Comme l’écoutille est ouverte, une extrémité du mur est interposée. Elle est à plus de 1” des deux agents, donc l’agent B est masqué. 
L’agent A devrait être situé à 3” de l’agent B, mais il faut mesurer en contournant le mur. L’agent A est donc à plus de 3” de l’agent B.
Un coin du mur est interposé, donc l’agent B est à couvert.
Une extrémité du mur est interposée, donc l’agent B est à couvert.
L’agent A a dépassé le coin du mur, donc ce dernier n’est pas interposé et l’agent B n’est pas à couvert. Si l’agent A était à gauche de la ligne noire en
pointillé, le mur serait interposé et l’agent B serait à couvert.

## ÉCOUTILLE

Une écoutille a deux états : ouverte ou fermée. Elle a deux parties : un point d’accès et un panneau. Les types de ces terrains dépendent de l’état de l’écoutille. Un agent peut effectuer l’action de mission **Actionner une écoutille** pour changer son état. Une écoutille commence la bataille fermée.
*Comme le point d’accès d’une écoutille ouverte est du terrain Exposé, les murs situés de part et d’autre doivent être pris en compte pour les règles masqué et à couvert à la place du point d’accès. 

### ACTIONNER UNE ÉCOUTILLE — 1 PA

- → Ouvrez ou fermez une écoutille dont le point d’accès est à portée de contrôle de l’agent actif.
- → Un agent peut effectuer cette action pendant une action **Sprinter** ou **Repositionnement**, et peut ensuite utiliser toute distance de mouvement qu’il lui reste.
- ⚠ Un agent ne peut pas faire cette action tant qu’il est à portée de contrôle d’un agent ennemi, ou si l’écoutille est ouverte et son point d’accès à portée de contrôle d’un agent ennemi.
*Ouvrir une écoutille peut mettre un agent à portée de contrôle d’un agent ennemi, auquel cas son action Sprinter ou Repositionnement s’arrête immédiatement (sauf s’il a des règles qui l’autorisent à se déplacer à portée de contrôle d’un agent ennemi).*
Tant qu’une écoutille est **fermée** : 
- Son panneau doit être complètement fermé. 
- Le point d’accès est le panneau sont un terrain de type Mur et Lourd. 
Tant qu’une écoutille est **ouverte** :
- Son panneau doit être **complètement** ouvert.
- Le point d’accès est Accessible, Insignifiant, Exposé.
- Le panneau est de type Mur et Lourd, et l’espace entre le panneau et le sol est Bloquant.
*Si un agent empêche un panneau de s’ouvrir ou de se fermer totalement, retirez-le temporairement de la killzone pour ouvrir ou fermer le panneau, puis replacez-le aussi près que possible de sa position initiale. Si un agent était à portée de contrôle d’un agent ennemi avant l’ouverture du panneau, il doit être replacé à portée de contrôle de cet agent ennemi.*

## COMBAT RAPPROCHÉ

La killzone : Gallowdark suit les règles additionnelles suivantes.

## ENVIRONNEMENT CONFINÉ

Les armes avec la règle Déflagration, Torrent et/ou x” Dévastatrice suivent aussi la règle d’arme Létale 5+.

## EN GARDE
Une fois pendant l’activation de chaque agent ennemi, après que cet agent ennemi a effectué une action, vous pouvez interrompre son activation et choisir un agent ami en garde pour effectuer gratuitement l’action **Tirer** ou **Combattre** (ou une action qui compte comme). Dans ce cas, cet agent ami ne peut pas contre-attaquer pendant le tournant.
De plus, l’agent ami peut effectuer l’action **Tirer** tant qu’il est à portée de contrôle d’un agent ennemi (ce qui supplante les conditions normales de l’action **Tirer**). On appelle cela un tir à bout portant, et suit les règles additionnelles suivantes :
- Ciblez l’agent ennemi à portée de contrôle de votre agent (même s’il n’est pas une cible éligible).
- Dégradez de 1 la caractéristique de Touche des armes de votre agent.
- Jusqu’à la fin de l’activation de l’agent ennemi que vous avez interrompue, votre agent ne peut pas riposter. 
*Déterminez normalement la cible de ces actions. Cela signifie par exemple que vous n’êtes pas obligés de cibler l’agent dont vous avez interrompu l’action.*

### GARDE — 1 PA

- → L’agent se met en garde (voir ci-dessus) jusqu’à ce qu’une de ces conditions soit remplie.
- Il effectue n’importe quelle action, se déplace ou est placé.
- Un agent ennemi termine une action dans sa portée de contrôle et vous n’interrompez pas cette activation (voir ci-dessus).
- Son ordre est changé.
- C’est le début du tournant suivant.
- ⚠ Cette action compte comme une action **Tirer**. Un agent ne peut pas faire cette action tant qu’il a un ordre de Dissimulation, ou tant qu’il est à portée de contrôle d’un agent ennemi.
*Garde est une action très pratique qui permet à un agent d’attaquer au moment opportun. Elle peut changer de manière radicale la dynamique du jeu en vous forçant à éviter les agents en garde, ou à réfléchir à comment utiliser cette action au mieux. Utilisez le pion Garde pour indiquer les agents en garde.*

## COMBATTRE À TRAVERS UNE ÉCOUTILLE
### COMBATTRE À TRAVERS UNE ÉCOUTILLE — 1 PA

- → Combattez avec l’agent actif. A l’étape Choisir un Agent Ennemi, choisissez un agent ennemi à 2” du point d’accès d’une écoutille ouverte que touche l’agent actif, et qui est situé de l’autre côté de celle-ci. Pendant toute cette action, ces agents comptent comme étant mutuellement à portée de contrôle.
- ⚠ Cette action compte comme une action **Combattre**. Un agent ne peut pas faire cette action tant qu’il est à portée de contrôle d’un agent ennemi, ou si son socle ne touche pas le point d’accès d’une écoutille ouverte.
*Cette action permet à un agent de combattre à travers une écoutille ouverte. Elle est pratique si l’ennemi bloque le passage de vos agents.*
> Le socle de l’agent A touche le point d’accès d’une écoutille ouverte. Il peut effectuer l’action **Combattre à travers une Écoutille** contre l’agent B ou C.
