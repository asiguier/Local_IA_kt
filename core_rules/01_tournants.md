# TOURNANTS

La séquence de chaque partie indique comment disposer le plateau de jeu, préparer votre kill team et remporter la victoire. De plus, une bataille se déroule généralement en 4 tournants, et chaque tournant inclut plusieurs phases, qui seront répétées jusqu’à ce que la bataille se termine, comme indiqué dans le pack de missions.
**Début du tournant > Phase de Stratégie > Phase d’affrontement > Fin du tournant**

## PHASE DE STRATÉGIE

1. **Initiative** : Le joueur ayant l’initiative active un de ses agents en premier. Au premier tournant, l’initiative est déterminée par le pack de missions. Ensuite, les joueurs tirent au dé et le vainqueur décide qui aura l’initiative. En cas d’égalité, le joueur qui n’avait pas au tournant précédent décide de l’ordre.
2. **Préparation** : Chaque joueur gagne 1PC. A chaque tournant après le premier, le joueur n’ayant pas l'initiative gagne 2PC. Chaque joueur prépare également tous ses agents (face claire d’un pion d’ordre).
3. **Manoeuvres** : En commençant par celui avec l’initiative, chaque joueur utilise une **MANOEUVRE STRATEGIQUE** (ex: subterfuge stratégique) ou passe. Répétez le processus jusqu’à ce que tous les deux passent d'affilée. Vous ne pouvez pas utiliser la même **MANOEUVRE STRATEGIQUE** plus d’une fois par tournant.

## PHASE D’AFFRONTEMENT

Le joueur ayant l’initiative active un agent préparé. Une fois l’activation terminée, son adversaire fait de même.
Répétez ce processus jusqu’à ce que tous les agents soient indisponibles, puis la phase d’affrontement se termine.
1. **Donner un ordre** : Choisissez l’ordre donné à l’agent. Il le garde jusqu’à sa prochaine activation.
> **Engagement** : L’agent peut effectuer normalement des actions et peut **contre-attaquer**.
> **Dissimulation** : L’agent ne peut pas effectuer les actions **Tirer** et **Charger**, et ne peut pas **contre-attaquer**. Toutefois, il n’est pas une cible éligible tant qu’il est à couvert.
2. **Effectuer des actions** : L’agent effectue des actions. Tant qu’il est occupé à cela, il est l’agent actif. Chaque action coûte des PA et chaque agent possède une limite de PA. De plus, il n’est pas possible d’effectuer la même action plusieurs fois pendant une activation. Le coût minimum d’une action est toujours de 0PA. Vous n’avez pas besoin de déclarer toutes les actions de votre agent lorsqu’il est activé. A la place, votre agent peut effectuer une action, puis vous pouvez décider l’action suivante en ayant constaté l’effet de la précédente.
Si une action est déclarée ou a commencé mais s’avère impossible à mener à bien, elle est annulée. Revenez à l’état qui précédait l’action. Cela ne compte pas comme ayant effectué cette action.
3. **Indisponible** : Quand l’activation d’un agent est terminée, ce dernier devient indisponible. Tant qu’il est indisponible, un agent n’est pas préparé.
**Contre - attaquer** : Tous vos agents sont indisponibles, mais pas ceux de l’adversaire ? Vous pouvez alors contre-attaquer (voir action universelles).
